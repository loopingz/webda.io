# SQLite backend (`@webda/sql` + `@webda/sqlite`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `Webda/SQLiteStore`, `Webda/SQLiteQueue` and `Webda/SQLitePubSub` on `node:sqlite` (in memory or file), reusing the Postgres "JSON document per row" repository through a new engine-neutral `@webda/sql` package, in one PR.

**Architecture:** `packages/postgres/src/sqlstore.ts` becomes `@webda/sql` (`SQLStore`, `SQLRepository`, `SQLComparisonExpression`) where every engine-specific SQL fragment is a method of a `SQLDialect`. `PostgresDialect` reproduces today's JSONB SQL character for character (guarded by a vitest snapshot taken before the refactor). `@webda/sqlite` adds `SQLiteDialect` (JSON1 functions), a ref-counted `DatabaseSync` registry shared by the three services, and the queue / pubsub ports. `MemoryStore` stays in `@webda/core` (decision from the issue discussion: Node 22 still warns on `node:sqlite`, the Registry default needs encryption, `MemoryRepository` is the parity reference).

**Tech Stack:** TypeScript (ESM, `webdac build`), vitest + `@webda/test` decorators, `node:sqlite` `DatabaseSync` (Node >= 22.13), `pg` (unchanged), `@webda/ql`.

**Spec:** https://github.com/loopingz/webda.io/issues/891 (the issue body is the spec; this plan follows its sections "Architecture", "Package layout", "SQLDialect contract", "Persistence modes", "SQLiteStore", "SQLiteQueue", "SQLitePubSub", "Acceptance criteria").

## Global Constraints

- Node engine floor stays `>=22.0.0`; `node:sqlite` is loaded with a dynamic `await import("node:sqlite")` so importing `@webda/sqlite` never fails or warns; a failed import throws `WebdaError.CodeError("SQLITE_UNAVAILABLE", "SQLite services require Node >= 22.13 (node:sqlite) ...")`.
- `@webda/sql` has no DB driver dependency; `@webda/sqlite` has no third-party runtime dependency (only `node:sqlite`).
- The SQL text produced for Postgres must not change: the snapshot of Task 1 must stay identical through Task 4.
- `import { SQLStore, SQLStoreParameters, SQLClient, SQLComparisonExpression, PostgresRepository } from "@webda/postgres"` keeps compiling (re-exports).
- SQLite placeholders are `?1`, `?2`, ... (never `$1`: a named parameter in SQLite).
- Conventions: DI only (no manual service instantiation in product code), `useLog` from `@webda/workout`, `WebdaError` subclasses from `@webda/core`, no edits to generated `*.schema.json` / `lib/**`; `webda.module.json` is generated by `webdac build` and committed; no `npx`; Prettier 120 columns, named functions, JSDoc on public APIs.
- Persistence options `key`, `cipher`, `compressionLevel` (MemoryStore-only) make `init()` throw `WebdaError.CodeError("SQLITE_UNSUPPORTED_PERSISTENCE", ...)`.
- `DatabaseSync` is synchronous: document it; no worker thread pool.
- Commits: conventional commits, each ending with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. A patch or collection attribute whose name is not `[A-Za-z0-9_]+` (e.g. `"a-b"`) must raise `Invalid attribute` from `SQLiteDialect` instead of producing a broken JSON path (Task 6 test `rejectsInvalidKeys`).
2. `persistence.path` inside a directory that does not exist yet must be created (Task 5 test `createsMissingParentDirectory`).
3. An empty patch `{}` must still produce a valid SQLite statement (`json_set` with zero pairs is a syntax error) (Task 6 test `emptyPatchKeepsData`).
4. Booleans and `Date` objects bound as statement parameters (write conditions) must bind as `1/0` and ISO text, since `node:sqlite` cannot bind them (Task 5 test `bindsBooleansDatesAndObjects`).
5. A read-only file database must reject writes with `WebdaError.CodeError("SQLITE_READONLY")`, not a raw `ERR_SQLITE_ERROR` (Task 5 test `readOnlyRejectsWrites`).

```ts
/** Database connection metadata */
export interface SQLDatabase {
  name: string;
}

/** Minimal SQL client interface compatible with pg.Client, pg.Pool and SQLiteClient */
export interface SQLClient {
  query: (q: string, values?: any[]) => Promise<{ rows: any[]; rowCount: number }>;
}

/** Typed result wrapper for SQL queries */
export interface SQLResult<T> {
  rows: T[];
  rowCount: number;
}

/** JSON value types a dialect can test for */
export type JSONType = "number" | "string" | "boolean" | "array" | "object";

/**
 * Quote a string as a SQL literal: single quotes are doubled so a value can never close the literal. Backslashes
 * stay literal (PostgreSQL `standard_conforming_strings`, SQLite has no escape character in '...' strings).
 * @param value - the string
 * @returns the SQL literal
 */
export function sqlString(value: string): string {
  return `'${value.replace(/'/g, "''")}'`;
}

/**
 * Engine syntax for the "one JSON document per row" model of {@link SQLRepository}: `uuid` key column, `data` JSON
 * column. Paths handed to a dialect are already validated (`[A-Za-z0-9_]+` segments) and safe to interpolate.
 *
 * Methods taking `args` push the parameters they bind and refer to them by `args.length`: the caller appends its own
 * parameters afterwards.
 */
export interface SQLDialect {
  /** Clause ordering text in code unit order: `COLLATE "C"` / `COLLATE BINARY` */
  readonly binaryCollation: string;
  /** Positional placeholder of the i-th (1-based) parameter: `$1` / `?1` */
  placeholder(i: number): string;
  /** The i-th parameter, a JSON text, as a JSON value: `$1::jsonb` / `json(?1)` */
  jsonParam(i: number): string;
  /** SQL text of the value at a path, NULL for a missing field and a JSON null */
  jsonText(path: string[]): string;
  /** JSON value at a path */
  jsonValue(path: string[]): string;
  /** JSON value at a path, a JSON null folded into SQL NULL (aggregations) */
  jsonValueOrNull(path: string[]): string;
  /** SQL text of a top-level key: `data->>'k'` */
  keyText(key: string): string;
  /** Condition: the JSON value has the type */
  isType(json: string, type: JSONType): string;
  /** Comparable number of a JSON value known to be a number */
  asNumber(json: string): string;
  /** Text of a JSON value known to be a string */
  asString(json: string): string;
  /** Attribute of a typed comparison: the number or boolean, NULL when the field has another type */
  typedAttribute(text: string, json: string, type: "number" | "boolean"): string;
  /** Null-safe `!=`: `IS DISTINCT FROM` / `IS NOT` */
  distinctFrom(left: string, right: string): string;
  /** Condition: the JSON value is an array holding the value (a literal, inlined) */
  contains(json: string, value: string | number | boolean): string;
  /** Case-sensitive LIKE condition on the text (`%` / `_`, `\%` / `\_` literal) */
  like(text: string, pattern: string): string;
  /** `CREATE TABLE IF NOT EXISTS` statement of a document table */
  createTable(table: string): string;
  /** Whether the error is a primary key / unique violation on insert */
  isUniqueViolation(err: unknown): boolean;
  /** Condition: the row has a `__type` key */
  hasStoredType(): string;
  /** The stored type of the row, rewritten through the legacy type map bound at `mapParam` (JSON text) */
  keptType(mapParam: number): string;
  /** The JSON value with `__type` set to the type expression */
  withStoredType(json: string, type: string): string;
  /** The JSON value shallow-merged with the patch (top-level keys replaced); binds what it needs */
  shallowMerge(json: string, patch: Record<string, any>, args: any[]): string;
  /** `data` without the top-level attribute; binds what it needs */
  removeKey(attribute: string, args: any[]): string;
  /** `data` with the counters incremented and `_lastUpdate` set to the ISO date; binds the increments */
  increment(entries: { property: string; value: number }[], updateDate: string, args: any[]): string;
  /** `data` with the item bound at `itemParam` appended to (index undefined) or set at `index` of the top-level array */
  setCollectionItem(attr: string, itemParam: number, index: number | undefined, updateDate: string): string;
  /** `data` with the item at `index` removed from the top-level array, `_lastUpdate` set */
  removeCollectionItem(attr: string, index: number, updateDate: string): string;
  /** Condition: the field of the item at `index` of the top-level array equals the parameter */
  collectionItemCondition(attr: string, index: number | undefined, field: string, valueParam: number): string;
  /** `data` with the UPDATE SET assignments applied: missing parents created, existing arrays indexed; binds values */
  bulkAssign(table: string, assignments: { field: string; value: any }[], args: any[]): string;
  /** Statement stamping `__type` = parameter 1 on the untyped rows of the table */
  backfillTypes(table: string): string;
  /** Statement returning `type`, `n` per stored type (parameter 1 = unreadable label, 2 = untyped label) */
  countStoredTypes(table: string): string;
  /** Condition: the `data` column is a JSON object */
  isObjectRow(): string;
  /** Decode a JSON column of a result row: the object (pg parses jsonb), parsed text otherwise */
  decode(value: any): any;
}
```

```ts
import { describe, expect, it } from "vitest";
import type { SQLClient, SQLDialect } from "./dialect.js";
import { sqlString } from "./dialect.js";
import { SQLRepository } from "./repository.js";

/** A dialect that tags every fragment so the repository assembly can be read in the SQL */
class TagDialect implements SQLDialect {
  binaryCollation = "COLLATE X";
  placeholder = (i: number) => `?${i}`;
  jsonParam = (i: number) => `J(?${i})`;
  jsonText = (p: string[]) => `T(${p.join("/")})`;
  jsonValue = (p: string[]) => `V(${p.join("/")})`;
  jsonValueOrNull = (p: string[]) => `N(${p.join("/")})`;
  keyText = (k: string) => `K(${k})`;
  isType = (j: string, t: string) => `${j} IS ${t}`;
  asNumber = (j: string) => `NUM(${j})`;
  asString = (j: string) => `STR(${j})`;
  typedAttribute = (t: string, j: string, type: string) => `TYPED(${j},${type})`;
  distinctFrom = (l: string, r: string) => `${l} <> ${r}`;
  contains = (j: string, v: any) => `${j} HAS ${JSON.stringify(v)}`;
  like = (t: string, p: string) => `${t} LIKE ${sqlString(p)}`;
  createTable = (t: string) => `CREATE ${t}`;
  isUniqueViolation = (err: any) => err?.code === "DUP";
  hasStoredType = () => "HASTYPE";
  keptType = (i: number) => `KEPT(?${i})`;
  withStoredType = (j: string, t: string) => `TYPED(${j}, ${t})`;
  shallowMerge = (j: string, patch: any, args: any[]) => {
    args.push(JSON.stringify(patch));
    return `MERGE(${j}, ?${args.length})`;
  };
  removeKey = (a: string, args: any[]) => {
    args.push(a);
    return `REMOVE(?${args.length})`;
  };
  increment = (e: any[], d: string, args: any[]) => {
    e.forEach(x => args.push(x.value));
    return `INC(${e.map(x => x.property).join(",")}, ${d})`;
  };
  setCollectionItem = (a: string, i: number, idx: number | undefined, d: string) => `SETITEM(${a}, ?${i}, ${idx}, ${d})`;
  removeCollectionItem = (a: string, idx: number, d: string) => `DELITEM(${a}, ${idx}, ${d})`;
  collectionItemCondition = (a: string, idx: any, f: string, p: number) => `ITEM(${a}, ${idx}, ${f}) = ?${p}`;
  bulkAssign = (t: string, as: any[], args: any[]) => {
    as.forEach(x => args.push(JSON.stringify(x.value)));
    return `ASSIGN(${as.map(x => x.field).join(",")})`;
  };
  backfillTypes = (t: string) => `BACKFILL ${t}`;
  countStoredTypes = (t: string) => `COUNT ${t}`;
  isObjectRow = () => "ISOBJ";
  decode = (v: any) => (typeof v === "string" ? JSON.parse(v) : v);
}

class Item {
  uuid!: string;
  name?: string;
  load(data: any) {
    Object.assign(this, data);
    return this;
  }
}

function make(rowCount = 1, data: any = JSON.stringify({ uuid: "a", name: "found" })) {
  const events: { q: string; values?: any[] }[] = [];
  const client: SQLClient = {
    query: async (q: string, values?: any[]) => {
      events.push({ q, values });
      return { rows: [{ data, uuid: "a" }], rowCount };
    }
```

```ts
import type { JSONType, SQLDialect } from "@webda/sql";
import { sqlString } from "@webda/sql";

/** PostgreSQL JSONB syntax: `uuid VARCHAR(255)` key, `data jsonb` document */
export class PostgresDialect implements SQLDialect {
  readonly binaryCollation = `COLLATE "C"`;
  placeholder(i: number): string { return `$${i}`; }
  jsonParam(i: number): string { return `$${i}::jsonb`; }
  jsonText(path: string[]): string { return `data#>>'{${path.join(",")}}'`; }
  jsonValue(path: string[]): string { return `data#>'{${path.join(",")}}'`; }
  jsonValueOrNull(path: string[]): string { return `NULLIF(data #> '{${path.join(",")}}', 'null'::jsonb)`; }
  keyText(key: string): string { return `data->>'${key}'`; }
  isType(json: string, type: JSONType): string { return `jsonb_typeof(${json}) = '${type}'`; }
  asNumber(json: string): string { return `(${json})::numeric`; }
  asString(json: string): string { return `${json} #>> '{}'`; }
  typedAttribute(text: string, json: string, type: "number" | "boolean"): string {
    return `(CASE WHEN jsonb_typeof(${json}) = '${type}' THEN (${text})::${type === "number" ? "numeric" : "boolean"} END)`;
  }
  distinctFrom(left: string, right: string): string { return `${left} IS DISTINCT FROM ${right}`; }
  contains(json: string, value: string | number | boolean): string {
    return `(CASE WHEN jsonb_typeof(${json}) = 'array' THEN ${json} END) @> ${sqlString(JSON.stringify([value]))}::jsonb`;
  }
  like(text: string, pattern: string): string { return `${text} LIKE ${sqlString(pattern)}`; }
  createTable(table: string): string {
    return `CREATE TABLE IF NOT EXISTS ${table} (uuid VARCHAR(255) NOT NULL, data jsonb, CONSTRAINT ${table}_pkey PRIMARY KEY (uuid))`;
  }
  isUniqueViolation(err: unknown): boolean {
    return typeof err === "object" && err !== null && "code" in err && (err as any).code === "23505";
  }
  hasStoredType(): string { return `data ? '__type'`; }
  keptType(mapParam: number): string { return `COALESCE($${mapParam}::jsonb -> lower(data->>'__type'), data->'__type')`; }
  withStoredType(json: string, type: string): string { return `${json} || jsonb_build_object('__type', ${type})`; }
  shallowMerge(json: string, patch: Record<string, any>, args: any[]): string {
    args.push(JSON.stringify(patch));
    return `${json} || $${args.length}::jsonb`;
  }
  removeKey(attribute: string, args: any[]): string {
    args.push(attribute);
    return `data - $${args.length}`;
  }
  increment(entries: { property: string; value: number }[], updateDate: string, args: any[]): string {
    let data = "data";
    for (const p of entries) {
      args.push(p.value);
      data = `jsonb_set(${data}, '{${p.property}}', (COALESCE(data->>'${p.property}','0')::int + $${args.length})::text::jsonb)::jsonb`;
    }
    return `jsonb_set(${data}, '{_lastUpdate}', '"${updateDate}"'::jsonb)`;
  }
  setCollectionItem(attr: string, itemParam: number, index: number | undefined, updateDate: string): string {
    let q = `jsonb_set(jsonb_set(data::jsonb, array['${attr}'],`;
    if (index === undefined) {
      q += `COALESCE((data->'${attr}')::jsonb, '[]'::jsonb) || jsonb_build_array($${itemParam}::jsonb))::jsonb`;
    } else {
      q += `jsonb_set(COALESCE((data->'${attr}')::jsonb, '[]'::jsonb), '{${index}}', $${itemParam}::jsonb)::jsonb)`;
    }
    return `${q}, '{_lastUpdate}', '"${updateDate}"'::jsonb)`;
  }
  removeCollectionItem(attr: string, index: number, updateDate: string): string {
    return `jsonb_set(jsonb_set(data::jsonb, array['${attr}'], COALESCE(((data->'${attr}')::jsonb - ${index}), '[]'::jsonb))::jsonb, '{_lastUpdate}', '"${updateDate}"'::jsonb)`;
  }
  collectionItemCondition(attr: string, index: number | undefined, field: string, valueParam: number): string {
    return `(data#>>'{${attr}, ${index}}')::jsonb->>'${field}'=$${valueParam}`;
  }
  bulkAssign(table: string, assignments: { field: string; value: any }[], values: any[]): string {
    // today's updateMany body from `const steps: string[] = [];` to the `data` template, returning `data`
  }
  backfillTypes(table: string): string {
    return `UPDATE ${table} SET data = data || jsonb_build_object('__type', $1::text) WHERE data->>'__type' IS NULL`;
  }
  countStoredTypes(table: string): string {
    return `SELECT CASE WHEN jsonb_typeof(data) IS DISTINCT FROM 'object' THEN $1
          WHEN jsonb_typeof(data->'__type') = 'string' AND data->>'__type' <> '' THEN data->>'__type'
          ELSE $2 END AS type, count(*)::int AS n FROM ${table} GROUP BY 1`;
  }
  isObjectRow(): string { return `jsonb_typeof(data) = 'object'`; }
  decode(value: any): any { return value; }
}
```

```ts
import { WebdaError } from "@webda/core";
import type { SQLClient, SQLDatabase } from "@webda/sql";
import type { DatabaseSync, SQLInputValue, StatementSync } from "node:sqlite";

/** Same name and role as MemoryStoreParameters.persistence */
export interface SQLitePersistence {
  /** Database file; relative paths resolve against the application directory */
  path: string;
  /** PRAGMA journal_mode=WAL (concurrent readers across processes) @default true */
  wal?: boolean;
  /** PRAGMA synchronous @default "NORMAL" with WAL, "FULL" otherwise */
  synchronous?: "OFF" | "NORMAL" | "FULL" | "EXTRA";
  /** Open the file read-only: writes are rejected with a WebdaError @default false */
  readOnly?: boolean;
}

/** Connection parameters shared by SQLiteStore, SQLiteQueue and SQLitePubSub */
export interface SQLiteConnectionParameters {
  /** Omitted: in-memory database lost on stop(); set: file database, every committed write is durable */
  persistence?: SQLitePersistence;
  /** Services giving the same database name share one handle @default { name: <service name> } in memory */
  database?: SQLDatabase;
  /** PRAGMA busy_timeout in ms @default 5000 */
  busyTimeout?: number;
  /** Extra PRAGMAs run on open, e.g. { cache_size: -64000 } */
  pragmas?: Record<string, string | number>;
}

type SQLiteModule = typeof import("node:sqlite");
const defaultLoader = (): Promise<SQLiteModule> => import("node:sqlite");
let loader: () => Promise<SQLiteModule> = defaultLoader;

/** Test-only: replace the node:sqlite loader (undefined restores the default) */
export function __setSQLiteLoader(custom?: () => Promise<SQLiteModule>): void {
  loader = custom ?? defaultLoader;
}

/**
 * Load node:sqlite lazily: importing @webda/sqlite never warns or fails, using it on an old Node does, clearly
 * @returns the module
 */
export async function loadSQLite(): Promise<SQLiteModule> {
  try {
    return await loader();
  } catch (err) {
    throw new WebdaError.CodeError("SQLITE_UNAVAILABLE", `SQLite services require Node >= 22.13 (node:sqlite): ${(err as Error).message}`);
  }
}

/**
 * A value node:sqlite can bind: booleans as 1/0, dates as ISO text, objects as JSON text, undefined as NULL
 * @param value - the value
 * @returns the bindable value
 */
export function bindable(value: any): SQLInputValue {
  if (value === undefined || value === null) return null;
  if (typeof value === "boolean") return value ? 1 : 0;
  if (value instanceof Date) return value.toISOString();
  if (typeof value === "object" && !(value instanceof Uint8Array)) return JSON.stringify(value);
  return value;
}

/** SQLITE_READONLY */
const READONLY = 8;

/** Adapter of a DatabaseSync to the SQLClient interface, with a bounded prepared statement cache */
export class SQLiteClient implements SQLClient {
  protected statements = new Map<string, StatementSync>();
  constructor(public readonly db: DatabaseSync, protected readonly cacheSize: number = 256) {}
  protected statement(sql: string): StatementSync {
    let stmt = this.statements.get(sql);
    if (stmt) return stmt;
    stmt = this.db.prepare(sql);
    if (this.statements.size >= this.cacheSize) {
      this.statements.delete(this.statements.keys().next().value!);
    }
    this.statements.set(sql, stmt);
    return stmt;
  }
  /** Statements returning rows run with all(), the others with run(); the method is async to honor SQLClient */
  async query(sql: string, values: any[] = []): Promise<{ rows: any[]; rowCount: number }> {
    const params = values.map(bindable);
    try {
      const stmt = this.statement(sql);
      if (/^\s*(SELECT|WITH|PRAGMA)\b/i.test(sql) || /\bRETURNING\b/i.test(sql)) {
        const rows = stmt.all(...params);
        return { rows, rowCount: rows.length };
      }
      return { rows: [], rowCount: Number(stmt.run(...params).changes) };
    } catch (err: any) {
      if (err?.code === "ERR_SQLITE_ERROR" && err.errcode === READONLY) {
        throw new WebdaError.CodeError("SQLITE_READONLY", err.message);
      }
      throw err;
    }
  }
}
```

```ts
import { useApplication, WebdaError } from "@webda/core";
import { EventEmitter } from "node:events";
import { mkdirSync } from "node:fs";
import { dirname, resolve } from "node:path";
import type { DatabaseSync } from "node:sqlite";
import { loadSQLite, SQLiteClient } from "./connection.js";
import type { SQLiteConnectionParameters, SQLitePersistence } from "./connection.js";

/** One open database shared by the services using the same key */
export interface SQLiteHandle {
  key: string;
  db: DatabaseSync;
  client: SQLiteClient;
  /** In-process notifications: `changed(table)` after a write by a service of this process */
  events: EventEmitter;
  refCount: number;
  /** Resolved file path, undefined in memory */
  path?: string;
}

const registry = new Map<string, SQLiteHandle>();
const PRAGMA_NAME = /^[A-Za-z_]+$/;
const PRAGMA_VALUE = /^-?[A-Za-z0-9_]+$/;
const SYNCHRONOUS = ["OFF", "NORMAL", "FULL", "EXTRA"];

/** Resolve a database path against the application directory (the working directory without an application) */
export function resolvePath(path: string): string {
  try {
    return useApplication().getPath(path);
  } catch {
    return resolve(path);
  }
}

/** Registry key: an explicit database name, else the file path, else the service name in memory */
export function databaseKey(params: SQLiteConnectionParameters, serviceName: string): string {
  if (params.database?.name) return `name:${params.database.name}`;
  if (params.persistence?.path) return `file:${resolvePath(params.persistence.path)}`;
  return `memory:${serviceName}`;
}

/** MemoryStore persistence options node:sqlite cannot honor: fail rather than pretend */
export function checkPersistence(persistence?: SQLitePersistence): void {
  for (const option of ["key", "cipher", "compressionLevel"]) {
    if (persistence && (persistence as any)[option] !== undefined) {
      throw new WebdaError.CodeError("SQLITE_UNSUPPORTED_PERSISTENCE", `SQLite persistence does not support '${option}': node:sqlite has no encryption or compression`);
    }
  }
}

/** Acquire (open or share) the database of the parameters; release it with releaseDatabase */
export async function acquireDatabase(params: SQLiteConnectionParameters, serviceName: string): Promise<SQLiteHandle> {
  checkPersistence(params.persistence);
  const key = databaseKey(params, serviceName);
  const existing = registry.get(key);
  if (existing) {
    existing.refCount++;
    return existing;
  }
  const { DatabaseSync } = await loadSQLite();
  let db: DatabaseSync;
  let path: string | undefined;
  if (params.persistence?.path) {
    path = resolvePath(params.persistence.path);
    mkdirSync(dirname(path), { recursive: true });
    const readOnly = params.persistence.readOnly ?? false;
    db = new DatabaseSync(path, { readOnly });
    if (!readOnly) {
      const wal = params.persistence.wal !== false;
      const synchronous = params.persistence.synchronous ?? (wal ? "NORMAL" : "FULL");
      if (!SYNCHRONOUS.includes(synchronous)) throw new WebdaError.CodeError("SQLITE_INVALID_PARAMETER", `Invalid synchronous mode ${synchronous}`);
      if (wal) db.exec("PRAGMA journal_mode = WAL");
      db.exec(`PRAGMA synchronous = ${synchronous}`);
    }
  } else {
    db = new DatabaseSync(":memory:");
  }
  db.exec(`PRAGMA busy_timeout = ${Math.max(0, Math.floor(Number(params.busyTimeout ?? 5000)))}`);
  for (const [name, value] of Object.entries(params.pragmas ?? {})) {
    if (!PRAGMA_NAME.test(name) || !PRAGMA_VALUE.test(String(value))) {
      db.close();
      throw new WebdaError.CodeError("SQLITE_INVALID_PARAMETER", `Invalid pragma ${name}=${value}`);
    }
    db.exec(`PRAGMA ${name} = ${value}`);
  }
  const handle: SQLiteHandle = { key, db, client: new SQLiteClient(db), events: new EventEmitter(), refCount: 1, path };
  registry.set(key, handle);
  return handle;
}

/** Release a handle: the database closes at the last release; unknown handles are ignored */
export function releaseDatabase(handle: SQLiteHandle): void {
  const entry = registry.get(handle.key);
  if (!entry || entry !== handle) return;
  entry.refCount--;
  if (entry.refCount > 0) return;
  registry.delete(handle.key);
  handle.events.removeAllListeners();
  try { handle.db.close(); } catch { /* already closed */ }
}

/** Test-only: close and forget every database */
export function __resetDatabases(): void {
  for (const handle of registry.values()) {
    handle.events.removeAllListeners();
    try { handle.db.close(); } catch { /* already closed */ }
  }
  registry.clear();
}
```

```ts
/** JSON1 path of validated segments: numeric segments index arrays */
export function jsonPath(path: string[]): string {
  return "$" + path.map(segment => (/^\d+$/.test(segment) ? `[${segment}]` : `.${segment}`)).join("");

/** GLOB pattern of a LIKE pattern: `%` → `*`, `_` → `?`, `\%` / `\_` literal, GLOB metacharacters escaped */
export function globPattern(like: string): string {
  let out = "";
  for (let i = 0; i < like.length; i++) {
    const c = like[i];
    if (c === "\\" && (like[i + 1] === "%" || like[i + 1] === "_")) {
      out += like[++i];
    } else if (c === "%") out += "*";
    else if (c === "_") out += "?";
    else if (c === "*" || c === "?" || c === "[") out += `[${c}]`;
    else out += c;
  }
  return out;
}

/** SQLite JSON1 syntax: `uuid TEXT` key, `data TEXT` JSON document, `?n` placeholders */
export class SQLiteDialect implements SQLDialect {
  readonly binaryCollation = "COLLATE BINARY";
  placeholder(i: number): string { return `?${i}`; }
  jsonParam(i: number): string { return `json(?${i})`; }
  /** Booleans read as `true` / `false` (not 0 / 1), everything else as its text; NULL for missing and JSON null */
  jsonText(path: string[]): string {
    const p = jsonPath(path);
    return `(CASE json_type(data, '${p}') WHEN 'true' THEN 'true' WHEN 'false' THEN 'false' ELSE CAST(data ->> '${p}' AS TEXT) END)`;
  }
  jsonValue(path: string[]): string { return `data -> '${jsonPath(path)}'`; }
  jsonValueOrNull(path: string[]): string { return `NULLIF(data -> '${jsonPath(path)}', 'null')`; }
  keyText(key: string): string { this.checkKey(key); return `data ->> '$.${key}'`; }
  isType(json: string, type: JSONType): string {
    switch (type) {
      case "number": return `json_type(${json}) IN ('integer', 'real')`;
      case "string": return `json_type(${json}) = 'text'`;
      case "boolean": return `json_type(${json}) IN ('true', 'false')`;
      default: return `json_type(${json}) = '${type}'`;
    }
  }
  asNumber(json: string): string { return `(${json} ->> '$')`; }
  asString(json: string): string { return `(${json} ->> '$')`; }
  typedAttribute(_text: string, json: string, type: "number" | "boolean"): string {
    return `(CASE WHEN ${this.isType(json, type)} THEN ${json} ->> '$' END)`;
  }
  distinctFrom(left: string, right: string): string { return `${left} IS NOT ${right}`; }
  contains(json: string, value: string | number | boolean): string {
    const literal = typeof value === "string" ? sqlString(value) : typeof value === "boolean" ? (value ? "1" : "0") : String(value);
    const type = typeof value === "string" ? "type = 'text'" : typeof value === "boolean" ? `type = '${value}'` : "type IN ('integer', 'real')";
    return `(json_type(${json}) = 'array' AND EXISTS (SELECT 1 FROM json_each(${json}) WHERE value = ${literal} AND ${type}))`;
  }
  like(text: string, pattern: string): string { return `${text} GLOB ${sqlString(globPattern(pattern))}`; }
  createTable(table: string): string {
    return `CREATE TABLE IF NOT EXISTS ${table} (uuid TEXT NOT NULL PRIMARY KEY, data TEXT NOT NULL CHECK (json_valid(data)))`;
  }
  isUniqueViolation(err: unknown): boolean {
    const e = err as any;
    return typeof e === "object" && e !== null && e.code === "ERR_SQLITE_ERROR" && (e.errcode === 1555 || e.errcode === 2067);
  }
  hasStoredType(): string { return `json_type(data, '$.__type') IS NOT NULL`; }
  keptType(mapParam: number): string { return `COALESCE(json(?${mapParam}) ->> lower(data ->> '$.__type'), data ->> '$.__type')`; }
  withStoredType(json: string, type: string): string { return `json_set(${json}, '$.__type', ${type})`; }
  shallowMerge(json: string, patch: Record<string, any>, args: any[]): string {
    const pairs: string[] = [];
    for (const [key, value] of Object.entries(patch ?? {})) {
      if (value === undefined) continue;
      this.checkKey(key);
      args.push(JSON.stringify(value));
      pairs.push(`'$.${key}', json(?${args.length})`);
    }
    return pairs.length ? `json_set(${json}, ${pairs.join(", ")})` : json;
  }
  removeKey(attribute: string, args: any[]): string {
    this.checkKey(attribute);
    args.push(attribute);
    return `json_remove(data, '$.' || ?${args.length})`;
  }
  increment(entries: { property: string; value: number }[], updateDate: string, args: any[]): string {
    const pairs = entries.map(({ property, value }) => {
      this.checkKey(property);
      args.push(value);
      return `'$.${property}', COALESCE(data ->> '$.${property}', 0) + ?${args.length}`;
    });
    return `json_set(data, ${pairs.join(", ")}, '$._lastUpdate', ${sqlString(updateDate)})`;
  }
  setCollectionItem(attr: string, itemParam: number, index: number | undefined, updateDate: string): string {
    this.checkKey(attr);
    const array = `COALESCE(data -> '$.${attr}', '[]')`;
    const updated = index === undefined
      ? `json_insert(${array}, '$[#]', json(?${itemParam}))`
      : `json_set(${array}, '$[${this.checkIndex(index)}]', json(?${itemParam}))`;
    return `json_set(data, '$.${attr}', ${updated}, '$._lastUpdate', ${sqlString(updateDate)})`;
  }
  removeCollectionItem(attr: string, index: number, updateDate: string): string {
    this.checkKey(attr);
    return `json_set(data, '$.${attr}', json_remove(COALESCE(data -> '$.${attr}', '[]'), '$[${this.checkIndex(index)}]'), '$._lastUpdate', ${sqlString(updateDate)})`;
  }
  collectionItemCondition(attr: string, index: number | undefined, field: string, valueParam: number): string {
    this.checkKey(attr);
    this.checkKey(field);
    return `data ->> '$.${attr}[${index === undefined ? "#-1" : this.checkIndex(index)}].${field}' = ?${valueParam}`;
  }
  /** One json_set: parents of dotted targets made objects (read from the stored row), then the values */
  bulkAssign(_table: string, assignments: { field: string; value: any }[], args: any[]): string {
    const pairs: string[] = [];
    const ensured = new Set<string>();
    for (const { field, value } of assignments) {
      const segments = field.split(".");
      for (let i = 1; i < segments.length; i++) {
        const parent = jsonPath(segments.slice(0, i));
        if (ensured.has(parent)) continue;
        ensured.add(parent);
        pairs.push(`'${parent}', json(COALESCE(CASE WHEN json_type(data, '${parent}') IN ('object', 'array') THEN data -> '${parent}' END, '{}'))`);
      }
      args.push(JSON.stringify(value));
      pairs.push(`'${jsonPath(segments)}', json(?${args.length})`);
    }
    return `json_set(data, ${pairs.join(", ")})`;
  }
  backfillTypes(table: string): string {
    return `UPDATE ${table} SET data = json_set(data, '$.__type', ?1) WHERE data ->> '$.__type' IS NULL`;
  }
  countStoredTypes(table: string): string {
    return `SELECT CASE WHEN json_type(data) IS NOT 'object' THEN ?1 WHEN json_type(data, '$.__type') = 'text' AND data ->> '$.__type' <> '' THEN data ->> '$.__type' ELSE ?2 END AS type, count(*) AS n FROM ${table} GROUP BY 1`;
  }
  isObjectRow(): string { return `json_type(data) = 'object'`; }
  decode(value: any): any { return typeof value === "string" ? JSON.parse(value) : value; }
  protected checkKey(key: string): void {
    if (!KEY.test(key)) throw new Error(`Invalid attribute: ${key}`);
  }
  protected checkIndex(index: number): number {
    if (!Number.isInteger(index) || index < 0) throw new Error(`Invalid index: ${index}`);
    return index;
  }
}
```

```ts
import { MessageReceipt, Queue, QueueParameters } from "@webda/core";
import { JSONUtils } from "@webda/utils";
import type { SQLiteConnectionParameters, SQLitePersistence } from "./connection.js";
import { acquireDatabase, releaseDatabase } from "./dbregistry.js";
import type { SQLiteHandle } from "./dbregistry.js";

/** Configuration for SQLiteQueueService */
export class SQLiteQueueParameters extends QueueParameters implements SQLiteConnectionParameters {
  /** Table backing the queue, created on init @default "webda_queue" @pattern /^[a-zA-Z_][a-zA-Z0-9_]*$/ */
  table?: string;
  /** Seconds a received but not deleted message stays invisible @default 30 */
  visibilityTimeout?: number;
  /** Messages per receiveMessage @default 10 */
  batchSize?: number;
  /** @default true */
  autoCreateTable?: boolean;
  persistence?: SQLitePersistence;
  database?: { name: string };
  busyTimeout?: number;
  pragmas?: Record<string, string | number>;
  load(params: any = {}): this {
    super.load(params);
    this.table ??= "webda_queue";
    this.visibilityTimeout ??= 30;
    this.batchSize ??= 10;
    this.autoCreateTable ??= true;
    this.busyTimeout ??= 5000;
    return this;
  }
}

/**
 * FIFO queue on a SQLite table (in memory, or a file shared by the processes of one host). A receive locks a batch
 * with one `UPDATE ... RETURNING` (SQLite serializes writers, so no SKIP LOCKED is needed); delete acks, an expired
 * visibility timeout makes the message visible again. Times are computed in JS and bound as parameters.
 *
 * Without `persistence` it is a drop-in alternative to MemoryQueue honoring the visibility timeout.
 *
 * @WebdaModda SQLiteQueue
 */
export default class SQLiteQueueService<T = any, K extends SQLiteQueueParameters = SQLiteQueueParameters> extends Queue<T, K> {
  protected handle?: SQLiteHandle;

  protected get table(): string {
    return this.parameters.table!;
  }

  /** Current time in ms, overridable by tests */
  protected now(): number {
    return Date.now();
  }

  async init(): Promise<this> {
    await super.init();
    if (!/^[a-zA-Z_][a-zA-Z0-9_]*$/.test(this.table)) {
      throw new Error(`Invalid table name "${this.table}" — must match /^[a-zA-Z_][a-zA-Z0-9_]*$/`);
    }
    this.handle = await acquireDatabase(this.parameters, this.getName());
    if (this.parameters.autoCreateTable) {
      await this.ensureTable();
    }
    return this;
  }

  protected async ensureTable(): Promise<void> {
    await this.client.query(`CREATE TABLE IF NOT EXISTS ${this.table} (id INTEGER PRIMARY KEY AUTOINCREMENT, payload TEXT NOT NULL CHECK (json_valid(payload)), created_at INTEGER NOT NULL, locked_until INTEGER)`);
    await this.client.query(`CREATE INDEX IF NOT EXISTS ${this.table}_visible_idx ON ${this.table} (locked_until, id)`);
  }

  protected get client() {
    if (!this.handle) throw new Error("SQLiteQueue not connected");
    return this.handle.client;
  }

  async sendMessage(event: T): Promise<void> {
    const client = this.client;
    this.metrics?.messages_sent?.inc();
    await client.query(`INSERT INTO ${this.table} (payload, created_at) VALUES (?1, ?2)`, [JSONUtils.stringify(event), this.now()]);
  }

  async size(): Promise<number> {
    if (!this.handle) return 0;
    const res = await this.client.query(`SELECT COUNT(*) AS count FROM ${this.table} WHERE locked_until IS NULL OR locked_until < ?1`, [this.now()]);
    return Number(res.rows[0].count);
  }

  async receiveMessage<L>(proto?: { new (): L }): Promise<MessageReceipt<L>[]> {
    const client = this.client;
    const now = this.now();
    const res = await client.query(
      `UPDATE ${this.table} SET locked_until = ?1 + ?2 WHERE id IN (SELECT id FROM ${this.table} WHERE locked_until IS NULL OR locked_until < ?1 ORDER BY id LIMIT ?3) RETURNING id, payload`,
      [now, this.parameters.visibilityTimeout! * 1000, this.parameters.batchSize]
    );
    return res.rows
      .sort((a, b) => Number(a.id) - Number(b.id))
      .map(row => {
        const payload = JSONUtils.parse(row.payload);
        return { ReceiptHandle: String(row.id), Message: proto ? Object.assign(new proto() as L & object, payload) : (payload as L) };
      });
  }

  async deleteMessage(id: string): Promise<void> {
    await this.client.query(`DELETE FROM ${this.table} WHERE id = ?1`, [Number(id)]);
  }

  getMaxConsumers(): number {
    return Math.max(1, Math.floor(this.parameters.maxConsumers / Math.max(this.parameters.batchSize!, 1)));
  }

  /** Test helper: empty the table and reset the id sequence */
  async __clean(): Promise<void> {
    if (!this.handle) return;
    await this.client.query(`DELETE FROM ${this.table}`);
    await this.client.query(`DELETE FROM sqlite_sequence WHERE name = ?1`, [this.table]);
  }

  async stop(): Promise<void> {
    if (this.handle) {
      releaseDatabase(this.handle);
      this.handle = undefined;
    }
    await super.stop();
  }
}

export { SQLiteQueueService };
```

```ts
import { PubSubService, ServiceParameters } from "@webda/core";
import { CancelablePromise, JSONUtils } from "@webda/utils";
import { useLog } from "@webda/workout";
import type { SQLiteConnectionParameters, SQLitePersistence } from "./connection.js";
import { acquireDatabase, releaseDatabase } from "./dbregistry.js";
import type { SQLiteHandle } from "./dbregistry.js";

/** Configuration for SQLitePubSubService */
export class SQLitePubSubParameters extends ServiceParameters implements SQLiteConnectionParameters {
  /** Channel name @default the service name lowercased */
  channel?: string;
  /** @default "webda_pubsub" @pattern /^[a-zA-Z_][a-zA-Z0-9_]*$/ */
  table?: string;
  /** Poll interval in ms for messages written by other processes @default 100 */
  pollInterval?: number;
  /** Seconds a message is kept for slow consumers before being purged @default 60 */
  retention?: number;
  /** Max messages fetched per poll @default 100 */
  batchSize?: number;
  /** @default true */
  autoCreateTable?: boolean;
  persistence?: SQLitePersistence;
  database?: { name: string };
  busyTimeout?: number;
  pragmas?: Record<string, string | number>;
  load(params: any = {}): this {
    super.load(params);
    this.table ??= "webda_pubsub";
    this.pollInterval ??= 100;
    this.retention ??= 60;
    this.batchSize ??= 100;
    this.autoCreateTable ??= true;
    this.busyTimeout ??= 5000;
    return this;
  }
}

interface Subscriber<T> {
  callback: (event: T) => Promise<void>;
  proto?: { new (): T };
  /** Last delivered message id: only messages published after the subscription are delivered */
  cursor: number;
}

/**
 * Pub/sub on a SQLite message log read through per-subscriber cursors: SQLite has no LISTEN/NOTIFY. Publishers of
 * this process wake the subscribers immediately through the shared handle; other processes on the same host (file
 * mode) are detected by polling `PRAGMA data_version` every `pollInterval`. Delivery is at-most-once per
 * subscriber while subscribed; a subscriber offline longer than `retention` misses messages (use SQLiteQueue for
 * guaranteed delivery). Not a network bus.
 *
 * @WebdaModda SQLitePubSub
 */
export default class SQLitePubSubService<T = any, K extends SQLitePubSubParameters = SQLitePubSubParameters> extends PubSubService<T, K> {
  protected handle?: SQLiteHandle;
  protected subscribers: Set<Subscriber<T>> = new Set();
  protected timer?: NodeJS.Timeout;
  protected dataVersion?: number;
  protected lastPurge = 0;
  protected polling = false;
  protected onChanged = (table: string) => {
    if (table === this.table) this.poll(true);
  };

  protected get table(): string {
    return this.parameters.table!;
  }

  protected channel(): string {
    return this.parameters.channel ?? this.getName().toLowerCase();
  }

  protected now(): number {
    return Date.now();
  }

  protected get client() {
    if (!this.handle) throw new Error("SQLitePubSub not connected");
    return this.handle.client;
  }

  async init(): Promise<this> {
    await super.init();
    if (!/^[a-zA-Z_][a-zA-Z0-9_]*$/.test(this.table)) {
      throw new Error(`Invalid table name "${this.table}" — must match /^[a-zA-Z_][a-zA-Z0-9_]*$/`);
    }
    this.handle = await acquireDatabase(this.parameters, this.getName());
    if (this.parameters.autoCreateTable) {
      await this.client.query(`CREATE TABLE IF NOT EXISTS ${this.table} (id INTEGER PRIMARY KEY AUTOINCREMENT, channel TEXT NOT NULL, payload TEXT NOT NULL, created_at INTEGER NOT NULL)`);
      await this.client.query(`CREATE INDEX IF NOT EXISTS ${this.table}_channel_idx ON ${this.table} (channel, id)`);
    }
    this.handle.events.on("changed", this.onChanged);
    return this;
  }

  async sendMessage(event: T): Promise<void> {
    const client = this.client;
    this.metrics?.messages_sent?.inc();
    const now = this.now();
    await client.query(`INSERT INTO ${this.table} (channel, payload, created_at) VALUES (?1, ?2, ?3)`, [this.channel(), JSONUtils.stringify(event), now]);
    const retentionMs = this.parameters.retention! * 1000;
    if (now - this.lastPurge >= retentionMs / 2) {
      this.lastPurge = now;
      await client.query(`DELETE FROM ${this.table} WHERE created_at < ?1`, [now - retentionMs]);
    }
    this.handle!.events.emit("changed", this.table);
  }

  async size(): Promise<number> {
    return 0;
  }

  consume(callback: (event: T) => Promise<void>, eventPrototype?: { new (): T }, onBind?: () => void): CancelablePromise {
    const cursor = Number(this.client.db.prepare(`SELECT COALESCE(MAX(id), 0) AS id FROM ${this.table}`).get()!.id);
    const entry: Subscriber<T> = { callback, proto: eventPrototype, cursor };
    this.subscribers.add(entry);
    this.timer ??= setInterval(() => this.poll(false), this.parameters.pollInterval);
    onBind?.();
    return new CancelablePromise(
      resolve => resolve(),
      async () => {
        this.subscribers.delete(entry);
        if (this.subscribers.size === 0 && this.timer) {
          clearInterval(this.timer);
          this.timer = undefined;
        }
      }
    );
  }

  /**
   * Deliver the new messages of each subscriber
   * @param force - read even when PRAGMA data_version did not change (a write by this process)
   */
  protected poll(force: boolean): void {
    if (!this.handle || this.polling || this.subscribers.size === 0) return;
    if (!force) {
      const version = Number(this.handle.db.prepare("PRAGMA data_version").get()!.data_version);
      if (version === this.dataVersion) return;
      this.dataVersion = version;
    }
    this.polling = true;
    try {
      const read = this.handle.db.prepare(`SELECT id, payload FROM ${this.table} WHERE channel = ?1 AND id > ?2 ORDER BY id LIMIT ?3`);
      for (const sub of [...this.subscribers]) {
        for (const row of read.all(this.channel(), sub.cursor, this.parameters.batchSize) as { id: number; payload: string }[]) {
          sub.cursor = Number(row.id);
          this.dispatch(sub, row.payload);
        }
      }
    } catch (err) {
      useLog("WARN", `SQLitePubSub poll failed: ${(err as Error).message}`);
    } finally {
      this.polling = false;
    }
  }

  protected dispatch(sub: Subscriber<T>, payload: string): void {
    let raw: any;
    try {
      raw = JSONUtils.parse(payload);
    } catch (err) {
      this.metrics?.errors?.inc();
      useLog("WARN", `SQLitePubSub invalid payload: ${(err as Error).message}`);
      return;
    }
    this.metrics?.messages_received?.inc();
    const event = sub.proto && raw ? Object.assign(new sub.proto() as T & object, raw) : (raw as T);
    const start = Date.now();
    sub
      .callback(event)
      .catch(err => {
        this.metrics?.errors?.inc();
        useLog("WARN", `SQLitePubSub callback failed: ${(err as Error).message}`);
      })
      .finally(() => this.metrics?.processing_duration?.observe((Date.now() - start) / 1000));
  }

  async stop(): Promise<void> {
    this.subscribers.clear();
    if (this.timer) {
      clearInterval(this.timer);
      this.timer = undefined;
    }
    if (this.handle) {
      this.handle.events.off("changed", this.onChanged);
      releaseDatabase(this.handle);
      this.handle = undefined;
    }
    await super.stop();
  }
}

export { SQLitePubSubService };
```

Reads in `poll` use `db.prepare(...).all/get` directly because `poll` runs from a timer and must stay synchronous (no overlapping polls). Add the export to `index.ts`.
