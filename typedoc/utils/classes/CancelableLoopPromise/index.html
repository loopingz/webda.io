CancelableLoopPromise

@webda/utils

Class: CancelableLoopPromise

Defined in: packages/utils/src/waiter.ts:271

A Promise subclass that repeatedly invokes callback in a loop until cancel() is called. Registered with CancelablePromise so that CancelablePromise.cancelAll() can stop it.
