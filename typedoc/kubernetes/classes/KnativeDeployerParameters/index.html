Platform the manifest targets: cloudrun adjusts the fields Cloud Run rejects or ignores

Cloud Run: no namespace (unless set to the project), minScale/maxScale annotations are camel-cased, target and envFrom are dropped, containerConcurrency is capped to 1000 (0 becomes the Cloud Run default), timeoutSeconds to 3600, the readiness probe becomes a startup probe and visibility becomes the run.googleapis.com/ingress annotation.

"knative"

revisionSuffix​

revisionSuffix: string

Defined in: kubernetes/src/deployers/knative.service.ts:308

Suffix of the revision name (<name>-<suffix>), empty to let Knative generate it

A named revision is deterministic: deploying the same template twice creates no new revision, and the suffix must change with the template (Knative refuses a different template under the same name).

Default​
