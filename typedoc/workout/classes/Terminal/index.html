Terminal

@webda/workout

Class: Terminal

Defined in: packages/workout/src/terminal/terminal.ts:32

Full-featured terminal UI with scrolling history, progress bars, and interactive input Provides a rich terminal interface with automatic screen updates and keyboard navigation Falls back to basic ConsoleLogger when not in a TTY environment

Example​

const output = new WorkerOutput();
const terminal = new Terminal(output, "INFO");
output.log("INFO", "Application started");
output.startProgress("task", 100, "Processing");
// Terminal displays logs with progress bars
terminal.close(); // Cleanup when done
