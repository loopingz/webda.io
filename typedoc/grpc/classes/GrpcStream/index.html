GrpcStream

@webda/grpc

Class: GrpcStream<RequestType, ResponseType>

Defined in: grpc/src/grpc-stream.ts:28

gRPC bidirectional stream handler.

Manages frame parsing (5-byte header: compressed flag + 4-byte big-endian length), message deserialization, and response framing for HTTP/2 gRPC streams.

Supports all four gRPC patterns:

  • Unary (single request, single response)
  • Server streaming (single request, stream of responses)
  • Client streaming (stream of requests, single response)
  • Bidirectional streaming (stream of requests, stream of responses)
