ModelRelated

@webda/models

Class: ModelRelated<T, L, K>

Defined in: packages/models/src/relations.ts:320

Define a 1:n relation on the current model to another model

T is the model to link to _K is the attribute in T to query

_K is not used but is required to complete the graph _K define the attribute to use to load the related objects

In SQL if current model is TableA and T is TableB, _K is the foreign key in TableB
