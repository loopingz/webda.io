BinariesImpl

@webda/core

Class: BinariesImpl<T>

Defined in: packages/core/src/services/binary.service.ts:797

Define a collection of Binary — many-cardinality binary attribute.

Tagged as a Behavior so its @Action methods register as <Model>.<Attribute>.<Action> operations alongside Single-Binary ones. Inherits from Array<BinariesItem<T>> so it preserves array semantics (iteration, indexed access, JSON.stringify-as-array). The transformer detects this Array-subclass shape and emits a push-based hydration coercion — see behaviors.ts:createHydrationBlock.
