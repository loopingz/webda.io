SQLiteRelationalDialect

@webda/sqlite

Class: SQLiteRelationalDialect

Defined in: sqlite/src/relational/dialect.ts:46

SQLite syntax of the relational layout: declared column types, inline foreign keys (DEFERRABLE INITIALLY DEFERRED, PRAGMA foreign_keys is set by the store), PRAGMA introspection, JSON1 operations on a named column. One writer at a time: no schema lock.
