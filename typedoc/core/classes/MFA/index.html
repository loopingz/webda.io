MFA

@webda/core

Class: MFA

Defined in: packages/core/src/models/mfa.model.ts:247

Multi-Factor Authentication behavior: second factors and recovery codes of the model holding it.

Actions are exposed as <Model>.<Attribute>.<Action>. The configured login attribute also completes authentication. Other attributes use the model canAct(context, "<attribute>.<action>") policy. Verification records the operation in the session and returns a proof bound to the owner and attribute.

Attempts are counted atomically on the owner: a model holding the behavior declares them, as User does, _mfaAttempts: number = 0 and _lastMfaAttemptAt?: number.
