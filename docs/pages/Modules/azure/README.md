# Azure

`@webda/azure` provides Azure Blob binaries, Cosmos DB persistence, Service Bus queues and pub/sub, Key Vault configuration/encryption, and Monitor logging. Authentication uses Azure's default credential chain or an explicitly configured service principal. Services contribute their ARM resources and managed identity permissions to the Azure deployers.

See the [package reference](https://github.com/loopingz/webda.io/tree/main/packages/azure#readme) for service configuration, supported Cosmos queries, verified Blob uploads, Service Bus settlement, Key Vault references and Monitor table setup.

See [Azure deployment](../../Deployments/Azure.md) for Container Apps, scheduled jobs, managed certificates, Functions Flex Consumption and CI authentication.
