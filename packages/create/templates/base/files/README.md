# __APP_NAME__

A [Webda](https://webda.io) v4 application.

```bash
__PM__ run debug   # build, then dev server with the interactive debug console on http://localhost:18080
__PM__ run serve   # build, then HTTP server on http://localhost:18080
__PM__ run build   # compile and generate webda.module.json
__PM__ test        # build, then run the tests
```

- Models: `src/models/`
- Services: `src/services/`
- Configuration: `webda.config.json`

Working with a coding agent? It reads `AGENTS.md`; skills are in `.agents/skills/`.
