importFromJson()​

importFromJson(source, options): Promise<ImportReport[]>

Defined in: packages/sql/src/relational/support.ts:430

Promote models from a JSON store (importFromJsonb): their rows are read through the JSON repository of the source, written through the relational repositories in one transaction (the deferred foreign keys let the links between imported rows point in any direction), and deleted from the source once committed when purge is set. A row whose key is already in the relational table is skipped. The models must already be listed by the store.

Parameters​

source​

SQLStore<any>

the JSON store holding the rows

options​

what to import

models?​

string[]

the model identifiers, every table root of the plan by default

purge?​

boolean

delete the imported rows from the source after the commit

repository​

(model, tx?) => RelationalRepository<any>

the relational repository of a model: the store's own (inside its event wrapper), or one bound to the handed-over connection

transact​

<R>(fn) => Promise<R>

runs the import in one transaction of the store: either one the repositories of the store join (the async chain transaction of withTransaction), or one on a connection it hands over

Returns​

Promise<ImportReport[]>

one report per model

Throws​

WebdaError.CodeError RELATIONAL_IMPORT_SOURCE when the source is this store or a relational store, MODEL_NOT_PLANNED for a model the store does not list, RELATIONAL_IMPORT_TABLE when the JSON table of a model is the relational one (name it differently with tables)

sync()​

sync(client, live?): Promise<SchemaStep[]>

Defined in: packages/sql/src/relational/support.ts:396

Bring the database to the plan (schemaSync) under the version registry: the JSON tables the plan references are created first, with the DDL of their store, then lock, read the live versions, check, DDL, register this version, unlock. A store whose registry may share the connection (SQLite) runs checkVersions and registerVersion itself, around the lock, and gives the live plans here

Parameters​

client​

SQLClient

live?​
