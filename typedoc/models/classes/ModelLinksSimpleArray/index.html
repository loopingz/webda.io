ModelLinksSimpleArray

@webda/models

Class: ModelLinksSimpleArray<T>

Defined in: packages/models/src/relations.ts:507

Link to a collection of objects

Uses composition instead of extending Array for better maintainability, performance, and type safety.

This allows to do a n:m or 1:n relation between two models

It does not require to have a symetric relation on the other side The array contains uuid of the linked objects
