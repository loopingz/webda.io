SQLTransactionState

@webda/sql

Class: SQLTransactionState

Defined in: packages/sql/src/transaction.ts:70

The transaction of a SQL store inside an operation: opened lazily by the first statement, then committed or rolled back once

It is the SQLClient of the repositories while the transaction is active; statements issued after its end (a promise left running by the operation) run on the fallback client, in autocommit.
