sync()​

sync(client, mode, hooks?): Promise<SchemaStep[]>

Defined in: packages/sql/src/relational/manager.ts:192

Bring the database to the plan

create and alter take the schema lock in a transaction, describe the database under it, apply the additive steps and commit; the online steps the dialect keeps out of the transaction (CREATE INDEX CONCURRENTLY, VALIDATE CONSTRAINT) run afterwards, one by one, and a failing one is logged and left out.

Parameters​

client​

SQLClient

a client whose statements run on one connection (the DDL runs in a transaction under the schema lock)

mode​

SchemaSyncMode

what to do: nothing, create the missing tables, also extend the existing ones, or only check

hooks?​

SchemaSyncHooks = {}

the registry hooks

Returns​

Promise<SchemaStep[]>

the applied steps

Throws​

SchemaDriftError in validate mode when anything is missing or differs
