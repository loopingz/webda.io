ModelLinksAny

@webda/models

Class: ModelLinksAny<K, T>

Defined in: packages/models/src/polymorphic.ts:132

Links to arbitrary model types. The second generic argument optionally restricts target model classes. Stored values are { model, key, ...custom }; links never cascade or remove dangling references automatically.
