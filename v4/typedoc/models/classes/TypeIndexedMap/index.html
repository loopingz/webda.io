TypeIndexedMap

@webda/models

Class: TypeIndexedMap<V>

Defined in: packages/models/src/repositories/typeindexedmap.ts:32

Storage map of a MemoryRepository indexing its entries by stored __type

Every model of a MemoryStore shares one storage map: without an index, a query parses every document of the store to find the ones of its model. This map keeps, for each stored __type, the keys holding it, so MemoryRepository.query only visits the entries of its model and subclasses.

The index is lazy: a write only records the key, its __type is read (one JSON.parse) the first time a query needs it. Every write path goes through set / delete / clear — repositories, persistence reload, raw patches of migrations — so the index can never miss an entry.

keysOfTypes returns the keys in the map insertion order, as iterating the map does: query results and offset continuation tokens are unchanged.
