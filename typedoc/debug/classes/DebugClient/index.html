DebugClient

@webda/debug

Class: DebugClient

Defined in: debug/src/tui/client.ts:26

HTTP + WebSocket client for the debug server API.

Connects to the debug server started by webda debug and provides typed methods for each introspection endpoint, plus a reconnecting WebSocket subscription for live request events.
