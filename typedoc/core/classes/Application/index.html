Application

@webda/core

Class: Application

Defined in: packages/core/src/application/application.ts:108

Map a Webda Application

It allows to:

  • Analyse imported modules
  • Scan code for Modda and generate the webda.config.json
  • Compile and Watch
  • Migrate from old configuration
  • List deployments

behaviors​

protected behaviors: object = {}

Defined in: packages/core/src/application/application.ts:170

Behaviors registry

Populated by loadModule from the top-level behaviors map of every loaded webda.module.json. Each entry holds the metadata blob emitted by the compiler so downstream consumers (DomainService, REST transport, etc.) can introspect the Behavior's declared actions and shape.

The Behavior class itself is NOT loaded at runtime: the per-model __hydrateBehaviors method emitted at compile time by @webda/content-mapper holds a static import to the class, so the runtime never needs to look it up by identifier.

isFinalModel()​

isFinalModel(model): boolean

Defined in: packages/core/src/application/application.ts:458

Return true if model is the one that wins when consumers look up the short name in the current namespace. Used by transports (REST, GraphQL, gRPC) so only one model gets exposed at a given URL / type when the app overrides a framework-provided class — e.g. WebdaSample/User shadowing Webda/User at /users.

A model is "final" when either:

  • it is the one resolved by completeNamespace(shortName), or
  • no other model exists with the same short name in the current namespace.

Parameters​

model​

string

the fully-qualified model identifier (e.g. "Webda/User")

Returns​

boolean

true when model should be treated as the canonical version
