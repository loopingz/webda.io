resolve()​

resolve(): Promise<void>

Defined in: packages/core/src/core/core.ts:298

Resolve services and their dependencies WITHOUT calling service.init().

After this completes:

  • All services declared in configuration are constructed.
  • Each service's resolve() has been called (via createService / bean registration).
  • this.initOrders is finalized (Store services first).
  • The configuration service (if any) has been fully initialized — it must run early so other services can read config during construction.

No non-configuration service.init() calls — no DB/network I/O is performed. Build-time hooks (@BuildCommand) run after this phase.

Returns​

Promise<void>
